# Claude Code registration

Build the harness first. Run this command from the target workspace, replacing the absolute path:

```bash
claude mcp add principal-agentic-harness -- node /ABSOLUTE/PATH/TO/principal-agentic-engineering-harness/dist/src/index.js
```

Set `HARNESS_WORKSPACE_ROOT` in the launch environment to the target project directory. Verify with `/mcp`.
