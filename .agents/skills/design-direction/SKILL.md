# Design Direction

1. Establish product type, audience, use case, brand personality, content reality, and primary user journey.
2. Audit an existing design system before creating a new one.
3. Define a distinct visual direction with typography, color, spatial rhythm, composition, component grammar, imagery, and motion.
4. Avoid generic gradients, gratuitous glassmorphism, excessive pills, meaningless bento grids, fake metrics, filler copy, decorative icons, and nonfunctional controls.
5. Use real product-specific content and realistic states.
6. Ensure all important decisions become documented design tokens or component rules.
7. Validate the direction against screenshots and actual page content, not only a moodboard.

Respect project constraints: no pink. Prefer charcoal, black, gray, white, navy, blue, sage, earthy green, brown, cream, with lime or orange accents only when justified.
